``` r
mr_trash_wheel_df = 
  read_excel("data/202610 Trash Wheel Collection Data.xlsx",
             sheet = "Mr. Trash Wheel", 
             range = "A2:N742") |> 
  janitor::clean_names() |> 
  select(dumpster:homes_powered) |> 
  mutate( 
    sports_balls = 
      as.integer(sports_balls), 
    trashwheel = "mr_trash_wheel_df", 
    year = as.numeric(year), 
    plastic_bottles = as.numeric(plastic_bottles)
    )
```

I first imported the Trash Wheel dataset using `read_excel()` from
`library(readxl)`. I specified which `sheet()` and `range()` to import
so as to exclude the trash wheel figure in the first row and the column
sums in the last row. I then cleaned my new data frame using
`clean_names()` and used `select()` to remove extra columns. I next used
the `mutate()` function to change the `sports_balls` values to whole
number integers. I then changed the `year` and `plastic_bottles`
variables to numeric, which allowed me to `bind_rows()` later on.
Finally, I added an additional column to identify which trash wheel was
responsible for which trash collection post-binding.

## Import and clean biomarker values data

``` r
biomarkers_df = 
  read_csv("data/data_mci/mci_amyloid.csv", 
           skip = 1, 
           na = c("", ".", "NA")) |> 
  janitor::clean_names() |> 
  pivot_longer(
    baseline:time_8,
    names_to = "years_elapsed", 
    values_to = "amyloid_42_40_ratio"
  ) |> 
   mutate(
    years_elapsed = case_match(
      years_elapsed, 
     "baseline" ~ 0, 
     "time_2" ~ 2,
     "time_4" ~ 4, 
     "time_6" ~ 6,
     "time_8" ~8
    )
  ) |> 
  rename(id = study_id)
```

I carried out a similar process of importing and cleaning for the
`biomarkers_df` dataset. In order to tidy the data, I used
`pivot longer()` because important information, specifically the years
elapsed since baseline, was stored in the column names, and biomarker
values were stored in the data cells. I added a column called
`years_elapsed` to detail the number of years elapsed since the
baseline, and I moved the biomarker values into a new column called
`amyloid_42_40_ratio`. Finally, I mutated the data in the
`years_elapsed` column to numerical values of years that had passed
using `case_match()`.
