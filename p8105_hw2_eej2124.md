## Read and clean the csv data

Read the data, clean the names, and retain line, station name, station
latitude / longitude, routes served, entrance type, entry, vending, and
ADA compliance. Converting entry variable from character to logical.

``` r
subway_df = 
  read_csv("data/NYC_Transit_Subway_Entrance_And_Exit_Data.csv", na = c("", ".", "NA")) |> 
  janitor::clean_names() |> 
  select(line:entry, vending, ada) |> 
  mutate(
    entry = case_match(
      entry, 
      c("YES") ~ TRUE,
      c("NO") ~ FALSE 
    )
  )
```

station_longitude, route1, route2, route3, route4, route5, route6,

ada variables. These variables are providing information about each NYC
MTA subway station, including name, subway line, subway route, and
whether the station entrance is ADA compliant. To clean the data, I used
the `clean_name` function from the `janitor` package to convert all
variable names to snake case, used the `select` function to retain only
specific variable columns, and finally used the `case_match` function to
convert the character variable `entry` to a logical variable. After
