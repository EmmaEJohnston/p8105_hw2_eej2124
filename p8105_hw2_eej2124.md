Read the data, clean the names, and retain line, station name, station
latitude / longitude, routes served, entrance type, entry, vending, and

``` r
subway_df =

           na = c("", ".", "NA")) |> 
  janitor::clean_names() |> 
  select(line:entry, vending, ada) |>

      c("YES") ~ TRUE,
```

``` r
mr_trash_wheel_df = 
  read_excel("data/202610 Trash Wheel Collection Data.xlsx",
             sheet = "Mr. Trash Wheel", 
             range = "A2:N742") |>

    sports_balls =
```

I first imported the Trash Wheel dataset using `read_excel()` from
`library(readxl)`. I specified which `sheet()` and `range()` to import
so as to exclude the trash wheel figure in the first row and the column
sums in the last row. I then cleaned my new data frame using
`clean_names()` and used `select()` to remove extra columns. I next used
the `mutate()` function to change the `sports_balls` values to whole
number integers. I then changed the `year` and `plastic_bottles`
variables to numeric, which allowed me to `bind_rows()` later on.
